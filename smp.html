Kelas 8 — Mobile App Dev, IoT & Simulasi Arduino (Tinkercad & Wokwi)

Mobile App: RC Controller MIT App Inventor

Pengembangan aplikasi Android App_RCcontroller_Javas_8A untuk mengontrol mobil/robot berbasis Bluetooth secara realtime:

  • UI/UX Layout: Kontrol navigasi (Maju, Mundur, Kiri, Kanan), Tombol Sein Kiri/Kanan, Hazard, dan Lampu Utama.
  • Bluetooth Client Logic: Blok pemrograman komunikasi serial (`ListPicker1` & `BluetoothClient1`).
  • Event Handling: Mengirimkan sinyal perintah karakter saat tombol ditekan (`TouchDown`) dan dilepas (`TouchUp`).
Robot Obstacle Avoider Tinkercad / Wokwi

Simulasi mobil robotik otonom berbasis Arduino Uno yang mampu menghindari rintangan secara otomatis:

  • Sensor & Actuator: Sensor Ultrasonik HC-SR04 & IC Motor Driver L293D untuk menggerakkan DC Motor.
  • Logika Navigasi: Mengukur jarak objek; jika jarak < 20 cm, robot akan belok/mundur otomatis.
if (distance < 20) {
  // Hindari halangan
  digitalWrite(motor1Pin1, LOW);
  digitalWrite(motor1Pin2, HIGH);
}
Tong Sampah Otomatis Tinkercad / Wokwi

Sistem tempat sampah pintar (Smart Dustbin) berbasis pencetus jarak ultrasonik:

  • Komponen: Arduino Uno, Sensor HC-SR04, Servo Motor (Pembuka tutup), LCD 16x2 I2C, dan LED Indikator.
  • Mekanisme: Deteksi tangan/objek < 50 cm mendatangkan aksi pembukaan servo 180° serta menampilkan pesan "Silahkan Buang / Terimakasih" pada layar LCD.
Pintu Garasi Otomatis Tinkercad / Wokwi

Sistem otomasi palang garasi kendaraan otomatis:

  • Pengoperasian: Sensor mengukur keberadaan mobil (< 100 cm) untuk memicu Motor Servo membuka pintu garasi.
  • Umpan Balik Visual: Layar LCD menampilkan status secara dinamis: "Membuka Garasi" atau "Pintu Garasi Tertutup".
LED Dance & Pengukuran Suhu Mikrokontroler

Eksperimen kontrol output digital sekuensial dan pembacaan sensor analog:

  • LED Dance (Pertemuan 6): Pemrograman animasi ritmis menggunakan 10 LED warna-warni yang dikontrol melalui pin digital Arduino dengan pewaktuan `delay(200)`.
  • Pengukuran Suhu: Integrasi sensor suhu (TMP36/DHT11) untuk memproses kalkulasi temperatur dalam derajat Celsius.
Smart Distance Alarm Wokwi

Simulasi sistem alarm jarak berbasis Arduino Uno yang memberikan respons visual dan suara saat objek terdeteksi.

  • Input Sensor: HC-SR04 mengukur jarak objek secara berkala.
  • Output Otomatis: Buzzer, LED, dan servo bekerja sebagai indikator serta respons alarm.
