Arsitektur & Infrastruktur Jaringan

MikroTik RouterOS Routing & Switching

Pendalaman materi sertifikasi tingkat MTCNA & MTCRE:

  • Basic Configuration: IP Addressing, DHCP Server/Client, NAT, dan DNS Resolver.
  • Routing Protocol: Static Routing, OSPF Dynamic Routing, dan Failover/Load Balancing (ECMP/PBR).
  • Network Security: Firewall Filter Rules, Mangle, Address List, dan Layer 7 Protocol.
  • Tunneling & Wireless: PPPoE Server, L2TP/IPsec VPN, dan Wireless PtP/PtMP Link.
# MikroTik OSPF Basic Setup
[admin@MikroTik] > routing ospf instance add name=default
[admin@MikroTik] > routing ospf network add network=192.168.10.0/24 area=backbone
Cisco Enterprise Systems CCNA Track

Penguasaan arsitektur jaringan skala besar (Cisco CCNA):

  • Switching Technologies: VLAN, Trunking 802.1Q, Inter-VLAN Routing (ROAS), LACP EtherChannel.
  • Redundancy Protocol: Spanning Tree Protocol (STP/RSTP) dan First Hop Redundancy Protocol (HSRP).
  • IP Services & Routing: Multi-area OSPFv2/v3, IPv6 Addressing, Standard/Extended ACL.
